Это имплементация Steam Audio со своей оберткой как плагин для Garry's mod. 
Он будет полностью заменять звуковой движок Source. 
В планах подная совместимость с "BackAudio Forge" (Fmod/Wwise-like software но для BackAudio Nexus + GMod).
