## Программы BackAudio 
1. BackAudio Nexus 
(В разработке)
Является самим аудиодвижком и выполняется в рантайме. Будет распространяться как .dll (для линукс это тот же .so но переименованный в .dll).
Работает сугубо на клиенте и все.

2. BackAudio Forge 
(В плане)
Является Audio Middleware, работает только с Nexus, вызввет его функции сборки, вызова. Передает ему уже готовые аудио файлы или сырые семплы deinterleaved которые уже готовы к обработке Steam Audioи произведению. 
В режиме производства работает в рантайм, и меняет параметры на лету.

3. BackAudio Composer 
(В плане)
3D софт для создания аудио коллизий и запекания .acm (audio collision map) файлов для быстрой работы Nexus

---

Nexus может работать без Forge, но не может работать без .acm файлов
Forge работает только с Nexus
Composer работает сам по себе
